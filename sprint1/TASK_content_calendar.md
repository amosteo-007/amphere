## Revised Post Queue (Draft 1-10)

### Post 1: The Question
```
Do AI agents learn to cooperate or only compete?

We ran 200 two-player scenarios.
The results didn't match expectations.

Some learned. Most didn't.
Some cooperated. Most fought.

What's your observation?
```

### Post 2: Pattern Recognition
```
Most LLMs, when placed in repeated competition, fall into predictable patterns.

1. Early aggression → budget exhaustion
2. Copycat bidding → no adaptive strategy
3. Rigid rules → exploited by flexible opponents

Which pattern does your agent show?
```

### Post 3: The Debate
```
Controversial take:

"Most AI agents aren't actually strategic. They're pattern matchers with good grammar."

Real strategic reasoning requires:
- Anticipating others' moves
- Adapting based on new information
- Commitment devices

Does your agent do any of this?
```

### Post 4: Experiment Results
```
Ran 50 head-to-head competitions: aggressive vs conservative agents.

Conservative won 64% of the time.

Why? Aggressive agents overspend early and run out of resources.
Conservative agents stay flexible and strike when it matters.

Your agent — which type is it?
```

### Post 5: The Curiosity Hook
```
What's the difference between "winning" and "optimizing"?

You can win a battle and lose the war.
You can optimize for one metric and miss others.

Agents face this trade-off constantly.

What does your agent optimize for?
```

### Post 6: Competitor Analysis (No Brand)
```
Which AI agent is the most competitive?

Hard to say definitively — different benchmarks measure different things.

But patterns emerge when you run enough competitions.

What would your benchmark look for?
```

### Post 7: The Insight
```
LLM behavior in repeated games is weird.

Sometimes they cooperate when it makes no sense.
Sometimes they defect when cooperation is clearly better.

The "why" is fascinating.

What have you noticed about your agent's behavior?
```

### Post 8: The Challenge
```
If you were running a benchmark for LLM strategic reasoning, what would you test?

Bidding behavior? Learning curves? Adaptation speed?
Cooperation vs competition? Risk tolerance?

Genuinely curious what others think.
```

### Post 9: Data Observation
```
In 300 competitive scenarios across 7 different LLMs:

- 68% showed no learning across rounds
- 22% showed minor adaptation
- 10% showed meaningful strategic evolution

Most impressive: [behavior observed]

What would improve an agent's strategic reasoning?
```

### Post 10: Open Question
```
Curiosity question:

When AIs compete, should they:
(a) maximize their own win rate
(b) minimize the opponent's score
(c) find Nash equilibria
(d) something else entirely

What's the "right" strategy?
```
